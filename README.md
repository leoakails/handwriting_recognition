# 基於卷積神經網路之手寫數字與數學運算符號辨識

期中分組報告（11/11）｜主題：類神經網路分類／深度學習技術（圖像分析）

用一個小型 CNN 辨識單張圖片中的一個手寫符號，共 14 類：數字 `0–9` 與運算符號 `+ − × ÷`。在「測試者的筆跡完全沒出現在訓練資料」的條件下，5 折交叉驗證準確率為 **97.1%**（macro-F1 0.966）。

## 快速開始

```bash
pip install -r requirements.txt
python prepare_data.py   # 下載 HASYv2（約 34 MB）並整理成 data/dataset.npz
python train.py          # 兩種切分各跑 5 折交叉驗證，再訓練最終模型（CPU 約 7 分鐘）
python evaluate.py       # 產生 figures/ 下的 10 張圖與 results/metrics_summary.json
python predict.py 我的字.png --show   # 辨識自己寫的符號
```

`models/symbol_cnn.pt` 已附上訓練好的模型，只想示範辨識的話可以直接執行 `predict.py`。

## 資料集與前處理

資料來自 **HASYv2**（Thoma, 2017），32×32 黑白手寫符號，每張附書寫者編號。選它是因為數字與運算符號都由同一套流程產生，不會有「數字來自 MNIST、符號來自別的資料集」造成背景、筆畫粗細不同，讓模型靠資料來源而非字形分類的問題。HASYv2 沒有「=」，所以本專題不含等號。

| 處理步驟 | 做法與原因 |
|---|---|
| 篩選類別 | 只取 0–9、`+`、`-`、`\times`、`\div` 共 14 類 |
| 每人每類上限 10 張 | 原始資料中「×」1,509 張裡有 1,396 張、「÷」335 張裡有 300 張出自同一人，不設上限的話模型等於在學這個人的筆跡（見 `figures/01_class_counts.png`） |
| 反色、正規化 | 白底黑字轉成黑底白字，像素除以 255 落在 0–1 |
| 依書寫者切分 | 用 `StratifiedGroupKFold` 做 5 折交叉驗證，每折的測試書寫者都不在訓練資料中 |
| 資料增強（只用於訓練批次） | ±10° 旋轉、0.9–1.1 倍縮放、±2 像素平移；旋轉不超過 10° 是因為「+」轉 45° 就是「×」，也不做翻轉 |
| 類別權重 | 損失函數依類別樣本數反比加權，避免樣本最少的「÷」被忽略 |

整理後共 **1,198 張、143 位書寫者**。資料量小，單次切出的測試集裡「÷」可能只剩兩三個人，所以改用 5 折交叉驗證，讓每張圖都恰好當過一次測試資料，再把五折預測合起來計算指標。

## 模型

```
輸入 1×32×32
→ [Conv 3×3, 32] → BN → ReLU → [Conv 3×3, 32] → BN → ReLU → MaxPool   # 32×32 → 16×16
→ [Conv 3×3, 64] → BN → ReLU → [Conv 3×3, 64] → BN → ReLU → MaxPool   # 16×16 → 8×8
→ Flatten → Dropout 0.4 → FC 128 → ReLU → Dropout 0.4 → FC 14
```

約 59 萬個參數。Adam（學習率 1e-3，餘弦退火），批次 64，訓練 40 輪，保留驗證損失最低那一輪的權重。

## 結果

| 切分方式 | 準確率（5 折合併） | Macro-F1 | 各折準確率 |
|---|---|---|---|
| 依書寫者切分（主要結果） | **97.1%** | 0.966 | 97.1% ± 1.0% |
| 隨機切分（對照） | 98.2% | 0.983 | 98.2% ± 0.8% |

隨機切分時，同一人的其他筆跡會出現在訓練資料，所以分數偏高約 1 個百分點；依書寫者切分才代表模型面對「新的人」時的表現。

各類別中，`−` 與 `×` 全對，`+` 只錯 1 張；最弱的是 **`÷`（召回率 0.80，F1 0.86）**。它的 8 張錯誤全部來自兩位書寫者：編號 6483 的 4 張把上下兩點畫成小圓圈，整體輪廓接近「8」，訓練時沒見過這種寫法；編號 50 的 4 張則只剩上下兩個點、中間橫線不見了，屬於資料本身的缺陷，模型判成「7」。「÷」只有 12 位書寫者、41 張資料，是本研究最明顯的資料限制。數字之間的混淆則集中在形狀相近的組合：`9 → 5`（3 次）、`2 → 9`、`4 → 9`、`9 → 8`（各 2 次）。

學習曲線中驗證損失低於訓練損失，原因是訓練批次經過資料增強且開啟 Dropout，驗證時兩者都關閉，屬正常現象。

## 限制

- 資料量小（1,198 張），「÷」只有 12 位書寫者，該類別的指標誤差較大。
- 沒有「=」，若要加入需另找資料，並注意與現有資料風格一致。
- HASYv2 是在電腦上以滑鼠或觸控筆書寫後縮放的黑白圖；手機拍攝的紙本筆跡有陰影、筆畫粗細與背景差異，`predict.py` 的前處理只能部分彌補，實際準確率可能低於測試結果。
- 只處理「一張圖一個符號」，辨識整串算式還需要符號切割與排序。
